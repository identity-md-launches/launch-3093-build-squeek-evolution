# Notices and asset provenance

The hamster, room, favicon and share illustration were drawn in this project as SVG geometry. The share PNG is a local raster export of `src/assets/share.svg`.

- **DM Sans:** Google Fonts, SIL Open Font License 1.1. The local Latin WOFF2 is used for the interface. See `font-license.txt` in this directory and [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/dmsans).
- **Wallet marks:** MetaMask, Rabby and Phantom SVGs were obtained from [RainbowKit's wallet connector assets](https://github.com/rainbow-me/rainbowkit/tree/main/packages/rainbowkit/src/wallets/walletConnectors), MIT; see `wallet-license.txt`. The Coinbase mark follows the provided wallet guide. Marks identify their respective wallet providers; no affiliation is implied.
- **Lucide:** interface icons supplied by the `lucide-react` dependency, ISC license.
- **React, Vite, wagmi, viem and TanStack Query:** dependencies listed in the manifest and lockfile; their upstream license files accompany package installations. Coinbase Wallet SDK is Apache-2.0.
- **Better Interface:** design guidance adapted from Jakub Krehel's Better Interface, MIT, and documentation guidance adapted from Paul Bakaus's Impeccable at commit `9d715cc4f5564a990ca8345abfdd5df6dc9b41c8`, Apache-2.0. Both provided notices and licenses are preserved in `better-interface-licenses.txt`.

The deployment pins and ABI signatures are factual protocol integration data from [Squeekchain's official developer documentation](https://docs.squeekchain.com/developers/) and [published Core ABI](https://docs.squeekchain.com/assets/abi/SqueekCore.json). This game creates no replacement Squeekchain contracts or tokens.
